## 🛠️ 輔助工具與範本

- **`1F_柱尺寸對照表.csv`**：結構柱翻模專用 CSV 對照範本（包含 `80x80`、`80x90`、`80x100`、`80x125` 等）。
- **`CleanColText.lsp`**：AutoCAD AutoLISP 批次文字清洗腳本（自動去除圖面上的多餘引號 `"` 與度數符號 `˚`）。
