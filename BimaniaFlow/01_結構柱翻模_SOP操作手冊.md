## 階段一：CAD 圖面檢查與前置清理 (AutoCAD)

### 1. 柱編號文字清理（去特殊符號）
- **踩坑點**：CAD 圖面上的柱文字若帶有引號 `""C11""` 或度數標記 `˚C11˚`，外掛的正規表達式會無法識別，導致報錯：`柱編號圖層上找不到結構編號（如 C1、C5）`。
- **標準動作**：
  1. 在 AutoCAD 中確認或搜尋柱文字。
  2. 將雙引號 `"`、單引號 `'`、度數符號 `˚` 全部替換清除，保留純淨文字（如 `C1`、`C11`、`CB1`）。
  3. 修改完成後，務必按 **`Ctrl + S` 儲存實體 DWG 檔**。

### 2. 確認圖元圖層分佈
在 AutoCAD 點擊柱子確認圖層：
- **柱框線圖層**：必須是封閉的矩形線條（本案為 `S-COL`）。
- **柱編號文字圖層**：柱名稱文字所在的圖層（本案為 `S-TEXT`）。
- **說明表格圖層**：旁邊圖說/尺寸表的文字圖層（本案為 `S-TEXTC`），避免與平面柱號混淆。

## 階段二：Revit 專案基準與 CAD 載入 (Revit)

### 1. 建立軸網（柱軸線）
- 進入對應樓層（例如 `1FL` 平面圖）。
- 依設計圖先將 X 向與 Y 向的網格（Grid）繪製完成，作為整體專案的空間定位骨架。

### 2. 載入 CAD 底圖
> [!CAUTION]
> **血淚禁忌：絕對不要使用 AutoCAD「傳送至 Revit」＋ Revit「CAD 剪貼簿」！**  
> **原因**：「CAD 剪貼簿」是以「匯入 (Import)」方式置入帶有時間戳記的死快照。若後續在 CAD 裡修改文字，Revit 裡的圖**完全不會同步更新**，且實體路徑遺失會導致外掛分析徹底失效。

- **標準動作（正規連結）**：
  1. 點選 Revit 上方選單：**【插入】 ➔ 【連結 CAD】（Link CAD）**。
  2. 選取實體的 DWG 檔案（例如桌面上的 `XS-PLANALL.dwg`）。
  3. 定位方式選擇「自動 - 原點到原點」或手動放置。
  4. 使用 Revit 的 **【對齊 (AL)】** 工具，將 CAD 的軸網精準對齊到 Revit 剛建好的網格上，並將 CAD 底圖**鎖定（Pin）**避免位移。

## 階段三：Revit 族群庫準備與防錯

### 1. 必須存在「結構柱」族群
- **踩坑點**：若專案內只有「建築柱（OST_Columns）」，結構柱翻模外掛會完全找不到可用的範本。
- **標準動作**：
  - 確認專案瀏覽器中【族群】➔【結構柱】下，載有**「混凝土柱-矩形」**（或自訂的 RC 結構柱族群）。

### 2. 嚴防族群「重名地雷」
- **踩坑點**：若族群內因為反覆複製、貼上而存在**兩筆一模一樣名稱的型號**（例如有兩個 `柱_C1-70*70`），外掛按建立時會噴出崩潰訊息：  
  `❌ 建立失敗: An item with the same key has already been added. Key: 柱_C1-70*70`
- **標準動作**：
  - 在左側專案瀏覽器展開該族群，檢查是否有同名型號，若有重複必須先刪除或重新命名。

## 階段四：外掛參數設定（圖層與 CSV 對照）

開啟外掛 **【結構柱翻模】** 視窗：

### 1. A. Data Source
- 選取剛才「連結 CAD」進來的底圖名稱。
- 目前樓層確認為 `1FL`。

### 2. B. Size Source（尺寸資料來源）
> [!IMPORTANT]
> **為什麼本案例必須用【CSV對照表】，而不能用【依底圖】？**  
> 因為圖面上的柱子旁邊**只有柱號（C1、C11），沒有標註斷面尺寸（80x80）**（尺寸都寫在圖紙旁邊的大表裡）。  
> 若選「依底圖」，外掛會抓周邊文字亂猜，抓到「基礎小樑」、「ELEV.」、「1F桿件尺寸表」，導致 20 幾根全部判定為「尺寸文字無法辨識」！

- **標準動作**：
  1. 點擊 **【CSV對照表】** 按鈕。
  2. 載入對應樓層的柱尺寸 CSV（例如 `1F_柱尺寸對照表.csv`）。
  3. **CSV 內容格式規範**：
     ```csv
     柱號,尺寸
     C*,80x80
     C1,80x80
     C10,80x100
     C12,80x90
     C15,80x125
     ```
     > **注意**：CSV 填寫的尺寸必須與圖面真實線條尺寸相符，否則會出現橘底警告「導入尺寸與圖面尺寸不一致」。

### 3. C. Layer Setting（柱圖層關聯性說明）
外掛有 3 個圖層設定，其核心作用如下：
- **柱邊緣圖層**（關鍵）：選取封閉矩形線條所在的圖層（如 `S-COL`）。
  - *作用*：外掛依據此圖層線條計算「圖面真實尺寸」與「中心點座標」。
- **柱編號圖層**（關鍵）：選取標示 C1、C2 的文字圖層（如 `S-TEXT`）。
  - *作用*：外掛以距離柱框中心最近的文字，匹配該柱子的柱號。
- **柱尺寸圖層**（輔助）：選取標註尺寸的圖層。使用 CSV 模式時外掛主要依賴 CSV，但建議選 `S-TEXT` 保持統一。

## 階段五：新增缺少的柱尺寸類型

當專案內缺少對應尺寸時，外掛表格會顯示「△ 未配對」，「對應族群類型」為空白。

### 操作步驟：
1. 點擊左下角 **D. Element Setting** 區塊的 **【新增柱類型】**。
2. 在彈出視窗中：
   - **複製來源**：選取專案現有的範本（如 `柱_C1-70*70`）。
   - **數值 (cm)**：輸入目標長寬（例如 柱寬 `80`、柱深 `80`）。
   - **新類型名稱**：輸入易辨識的名稱（例如 `柱-80X80cm`）。
   - 點擊 **【建立】**。
3. 若圖面有多種尺寸，依序建立：
   - `柱-80X80cm`（佔最大宗，建立完直接配對 18 根）
   - `柱-80X90cm`
   - `柱-80X100cm`
   - `柱-80X125cm`

## 階段六：執行分析、嚴格檢核與確認建立

### 1. 執行分析
點擊左下角 **【執行分析】**。

### 2. 表格 5 大通關檢核指標（必須全數符合）：
| 欄位 | 檢核標準 | 異常處理 |
| :--- | :--- | :--- |
| **幾何類型** | 必須皆為「矩形柱」 | 若有異常形狀，檢查 CAD 線條是否閉合 |
| **圖面尺寸 vs 導入尺寸** | 兩欄尺寸必須完全一致（例如皆為 `80x80`） | 若出現橘底「尺寸不一致」，代表 CSV 尺寸打錯，需更新 CSV |
| **對應族群類型** | **絕不能有空白**，必須正確指向對應型號 | 空白代表尚未建立或未指定，需至步驟五建立 |
| **狀態欄** | 必須全為 **`☑ 已配對`** | 若顯示「△ 未配對」，檢查族群類型是否有被選中 |
| **標記欄（最右欄）** | 欲建立的柱子勾選 `☑`；非柱子（如開口 `*1` 40x40 OPEN）**取消勾選** | 將假柱或管道間開口取消勾選，避免建出多餘構件 |

### 3. 確認建立與驗收
1. 檢核無誤後，點擊左下角 **【確認建立】**！
2. 外掛跑完後，切換至 **Revit 預設 3D 視圖（{3D}）**。
3. 隨機點選一根柱子，檢查右側【性質】面板：
   - **基準樓層**：是否為 `1FL`（偏移 0）。
   - **頂部樓層**：是否正確連至 `2FL`（偏移 0）。
   - **尺寸與族群**：斷面尺寸是否精準無誤。

## 血淚踩坑常見錯誤與排解對照表

| 遇到的現象 / 錯誤訊息 | 根本原因 | 唯一正確解法 |
| :--- | :--- | :--- |
| **分析結果顯示「共 0 根柱」** | 用了「CAD 剪貼簿」，DWG 名稱帶有時間戳記且為匯入死圖，外掛匹配失效。 | 刪除匯入圖，改用【插入】➔【連結 CAD】真實 DWG 檔。 |
| **柱編號圖層上找不到結構編號** | CAD 的柱文字帶有引號 `""C11""` 或度數標記 `˚C11˚`。 | 在 AutoCAD 將特殊符號取代清除，存檔後在 Revit 重新載入。 |
| **尺寸文字無法辨識（大樑/基礎小樑/ELEV）** | 尺寸來源誤選「依底圖」，外掛去抓柱號周圍非尺寸的說明文字。 | 將尺寸來源改為【CSV對照表】，載入配對好的 CSV 檔。 |
| **導入尺寸與圖面尺寸不一致（橘底）** | CSV 裡面的尺寸數值（如打成 60x60）與圖面真實尺寸（80x80）打架。 | 修正 CSV 內的尺寸數值，重新點【CSV對照表】載入並重跑分析。 |
| **❌ 建立失敗: An item with the same key has already been added** | Revit 結構柱族群內存在兩個同名型號（重名衝撞）。 | 在專案瀏覽器中找到重複名稱的族群類型，刪除多餘的那一個。 |
